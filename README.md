# Лайтовая

Сайт столярной мастерской с медиатекой и онлайн-записью.

Сборка: `node worker/build.mjs`. Серверу нужен Cloudflare D1 с привязкой `DB`. Миграции находятся в `drizzle/`. Ветка `gh-pages` использует общий сервер записи на Sites. После бронирования сайт открывает Telegram с заполненным черновиком заявки.
